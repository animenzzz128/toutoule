工作职责
关于我们
质效研发部肩负着以 AI 重构公司级下一代质量与研发效能体系的使命。我们希望基于 AI 技术，打造全新版本的研发工具，结合 LLM 辅助、LLM 原生能力，串联从需求理解到发布部署的全流程，为小红书的技术团队提供业界顶尖的“武器装备”；同时希望通过这些“武器装备”，让每一位小红书的研发人，都有机会成为“超级个体”。
工作职责：
1、负责质效领域大模型产品某条功能线的全生命周期：负责研发 Agent、AI Coding（IDE 插件 / CLI）、AI Testing 等方向的产品设计，深度结合研发团队实际业务需求，推动产品在公司内各研发团队的应用与落地，完成从原型验证到规模化推广的完整交付；
2、深入研发一线场景，识别 AI 能真正提效的切入点：通过用户行为分析与一线访谈，精准定位大模型应用的关键价值点与能力边界，把研发痛点转化为可落地的 Agent 方案，而不是做功能堆砌；
3、搭建产品数据监测与评测体系，追踪核心指标口径，通过深度分析用户使用数据与反馈，形成数据驱动的产品决策闭环；
4、追踪 AI Coding 与 Agent 领域一手动态，形成自己的方向判断并推动落地；
5、与业务团队协同，快速构建专属 AI 能力。
任职资格
1、本科及以上学历，计算机科学、软件工程、数据科学、人工智能等相关专业优先；
2、具备扎实的产品设计基础：能独立完成需求拆解、用户场景分析、方案设计与 PRD 撰写，产出结构清晰、逻辑严谨、可直接进入评审的文档；
3、具备项目推进能力：能拆解里程碑、跟进进度、识别风险，推动跨职能协作按期交付；沟通表达清晰，能向不同角色（研发 / 设计 / 业务方）准确传达产品意图；
4、深度使用过至少一款 AI Coding 工具（Cursor / Claude Code / Copilot / CodeWiz / Windsurf 等）：不是“试过”，而是真的用它完成过完整项目或持续交付过代码，面试会现场追问工作流细节；
5、学习能力和自驱力突出，能在不确定性中主动探索方向。
【加分项】
1、有可展示的独立产出：产品分析文章、独立做过的产品 / 工具 / 开源项目、竞赛成果均可，但必须是你独立思考的产物，投递时附上链接或文档。给开源项目提交过被合并的 PR；
2、有 AI 产品、开发者工具、DevTools 相关实习经历。
加入我们，你将获得：
1、直接影响数千名小红书研发工程师日常工作方式的机会，你做的每一个决策都在重塑公司的研发范式；
2、直面 LLM 在实际工程场景落地的关键难题：可靠性、可控性、规模化，以及 PM 视角独有的“能力边界与产品价值匹配”问题；
3、完善的 Mentor 带教与成长机制，与一群对技术和产品充满热情的伙伴，共同探索人机协作的研发新范式。
